# 포레이로 프리셋 — 이식판

이 폴더에서 작업할 때는 **반드시 아래를 먼저 읽어라.** 추측하지 마라.
사용자가 **"포레이로 프리셋으로 만들어줘"** · **"포레이로프리셋 불러와"** 하면 이 문서대로 한다.

드라마·영화 장면을 **나레이션으로 끌고 가는** 세로 숏폼이다. 유튜브 @포레이로(토메이로 문체 포함)를
실측해 만들었고, 2026-09-05 ~ 09-15 사이에 사용자가 하나씩 지적해 박은 규칙이 전부 들어 있다.

## 읽는 순서 — 전부 읽고 시작한다

0. **★`docs/포레이로-지침서.md`** — 사용자가 못 박은 것 전부. **처음부터 끝까지** 읽어라.
1. **★`docs/포레이로-지침서-부록.md`** — 지침서를 쓴 뒤(09-09 ~ 09-15)에 새로 박힌 것.
   **지침서와 숫자·방법이 다르면 부록이 이긴다.**
2. **`presets/포레이로/README.md`** — 절차와 원고(나레) 쓰는 법.
3. **`docs/PLAYBOOK-포레이로.md`** — §17 실측값과 함정 전량. (§8 저작권 · §10 PowerShell 함정 · §16 벤치마킹도 같이 옮겼다)
4. **`docs/claude-memory/`** — 사용자가 대화에서 못 박은 **작업 방식**. `MEMORY.md` 가 목차다.
5. 규격 수치 `presets/포레이로/spec.py` · 지난 이력 `docs/SESSION-LOG-포레이로.md` ·
   지난 편 설계도 `examples/<편>/episode.py` (+ `_업로드.txt` 업로드 세트 예시).

★문서 안에 `docs/PLAYBOOK.md §17-…` 이라고 적힌 것은 이 판에서 **`docs/PLAYBOOK-포레이로.md`** 에 있다.
  §8·§10·§16·§17 만 옮겼다. 나머지 절 번호(§12·§13·§18 등)는 다른 채널 것이라 뺐다.

## 한 줄

★**나레이션이 주인이고 드라마는 그림(B롤)이다.** 원본 대사는 가장 센 것 3~4개만 끼운다.
★**0초 프레임은 시간 순서를 무시하고 그 편에서 가장 센 그림**을 놓는다.
★줌·팬을 넣지 않는다. 다른 채널(딸기우유 등)의 엔진·습관을 끌어오지 마라.

## 절차 — 순서를 바꾸지 마라

```powershell
$env:PATH = "$HOME\.volcano\venv\Scripts;$env:PATH"
$P = "presets\포레이로"
$E = "<편폴더>"                       # 예: n07_무언가  (새로 만든다)

python "$P\prep.py"      $E <URL 또는 로컬파일> [시작초] [끝초]   # src.mp4 · 컷 후보 · episode.py 뼈대
python scripts\_asr_sm.py "$E\src.mp4" "$E\asr_ko.json" ko         # ★대사 구간 단어 시각 전사
#   ... 국면 지도를 떠서 episode.py 의 HEAD1/HEAD2 · WORK · BLOCKS · EFFECTS 를 채운다 ...
python "$P\dlgcheck.py"  $E "$E\asr_ko.json" 0    # ★자막 없는 말 0개여야 다음으로
python "$P\get_fonts.py" $E
python "$P\tts.py"       $E                         # SeHee 1.2배
python "$P\align.py"     $E                         # 나레 자막을 실제 발화 시각에
python "$P\reframe.py"   $E                         # ★화자를 화면 안에
python "$P\build.py"     $E                         # ★[포레이로 규격 위반] 칸이 안 뜨면 통과
python "$P\synccheck.py" $E                         # ★★씽크를 재서 확인 (0.10초 넘으면 깨진 것)
python "$P\cutsheet.py"  $E                         # ★컷 눈검사 — cutsheet.jpg 를 반드시 연다
```

전 편을 굽지 않고 훑는 검사: `python presets\포레이로\scan.py` (물음표·컷 자리) ·
`python presets\포레이로\fxscan.py` (효과자막 영상 밖·두 줄).

완성본은 `포레이로/` 폴더로 모이고, **사용자 납품 폴더 `~/Downloads/드라마/`** 에도 영상+업로드 세트를 복사한다(2026-09-15 지시).

## 최상위 규칙 (사용자가 박은 것)

- **다음 단계가 분명하면 묻지 말고 계속한다.** 갈림길이 크게 갈리거나(소재 선택),
  되돌리기 어렵거나 바깥으로 나가는 일(업로드·공개·삭제)만 묻는다. 막히면 방법을 바꿔 다시 한다.
- **완성본 영상 하나 + 업로드 세트(제목·설명글·해시태그)를 한 벌로 건넨다.** 중간 파일 목록을 늘어놓지 마라.
  업로드 세트는 코드블록으로 답에 보여 주고 `포레이로/<편>_업로드.txt` 로도 둔다.
- **한 번에 한 프리셋만.** 포레이로 작업 중에 다른 채널의 소재·엔진을 대안으로 꺼내지 마라.
- **작업이 한 덩이 끝나면 `docs/PLAYBOOK-포레이로.md` 에 규칙을, `docs/SESSION-LOG-포레이로.md` 에 이력을
  더하고 (git 저장소면) 커밋한다.** 사용자가 "최상위 강제 규칙"이라고 못 박았다.
- **적어 두는 것만으로는 안 지켜진다.** 사용자가 새로 지적한 규칙은 `build.py` 의 검사로 박아라.
- **불법 스트리밍 사이트 파일(누누티비 등)은 쓰지 않는다.** 이름만 바꾼 파일도 길이·프레임을 재서 거른다.
  남의 채널 영상이면 사용 권한을 사용자에게 확인한다.
- API 키·미디어 파일은 **절대 커밋하지 않는다.**

## 환경

- 전용 파이썬: `~/.volcano/venv/Scripts/python.exe` (numpy · opencv-python · fonttools · brotli · pillow · yt-dlp)
  ★윈도 기본 `python.exe` 는 Microsoft Store 스텁일 수 있다 — 반드시 venv 파이썬으로 돌린다.
- ffmpeg 7 이상 (ass 필터 필요 · `-/filter_complex <파일>` 문법을 쓴다). `drawtext` 는 쓰지 마라.
- API 키는 `~/.volcano/keys/` 에 값만 적은 파일로 둔다 —
  `typecast`(나레 · 필수) · `speechmatics`(전사 · 필수) · `gemini`(시대극 두 번째 귀 · 선택)
- 글꼴: 그리운 코코초이툰(`fonts/` 에 동봉, 설치 스크립트가 사용자 글꼴로 넣는다) · BM 도현체(자동으로 받는다)
- 얼굴 모델 `models/yunet.onnx` · 장면전환음 `LLJtlSPtAMU/sfx/whoosh.wav` (동봉)
- 처음 열었거나 뭔가 안 되면: `python bootstrap_포레이로.py` — 빠진 도구·키·파일을 알려 준다.
