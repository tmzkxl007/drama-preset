# 포레이로 프리셋 — 드라마·영화 장면을 나레이션으로 끌고 가는 숏폼

사용자가 **"포레이로 프리셋으로 만들어줘"** 하면 이 문서를 열어 그대로 따라간다.

규격 수치는 `spec.py`, 실측 근거는 `docs/PLAYBOOK.md` §17, 원자료는 `forey_probe/`.
편마다 다른 것(소재·구간·제목 문구·블록표)은 편 폴더의 `episode.py` 에 넣는다.

---

## 0. 이 프리셋의 한 줄

> **나레이션이 이야기를 끌고 가고, 드라마는 그림(B롤)일 뿐이다.**

포레이로 10편을 재 보면 원본 대사가 끼어드는 횟수가 **편당 2~6번**뿐이다.
같은 잣대로 잰 무비대장은 26번, 마음 한조각은 56번이다(§16).
**대사를 들려주려 하면 이 프리셋이 아니다.** 내가 이야기를 해 주고, 원본 대사는
결정적인 순간에만 튀어나오게 둔다.

---

## 1. 만들기 전에

- **소재 권한을 확인한다.** 남의 드라마·영화다. PLAYBOOK §8 대로 사용자에게 확인받고,
  설명문에 `* 작품: <작품명>` 을 반드시 넣는다(포레이로가 하는 방식).
- **불법 스트리밍 사이트 파일은 쓰지 않는다.**

## 2. 절차

```powershell
$env:PATH="~\.volcano\venv\Scripts;$env:PATH"
$P = "~\volcano_work\presets\포레이로"
$E = "~\volcano_work\ep01_무언가"     # 편 폴더 (새로 만든다)

python "$P\prep.py"      $E <URL 또는 로컬파일> [시작초] [끝초]
#   → src.mp4 · cuts_candidates.txt · episode.py 뼈대가 생긴다
#   ... episode.py 의 HEAD1/HEAD2 · BLOCKS · CUTS · EFFECTS 를 채운다 (3~6장) ...
python "$P\get_fonts.py" $E
python "$P\tts.py"       $E

```

파일 구성 — **딸기우유 엔진을 부르지 않는다. 여기 것이 전부다.**

| 파일 | 하는 일 |
|---|---|
| `spec.py` | 규격 수치(§17 실측값). `base.py` 에서 화면·색·자리·길이를 전부 덮어쓴다 |
| `prep.py` | 소재 놓기 → 하드섭 띠 찾기 → 장면 전환 훑어 컷 후보 → `episode.py` 뼈대 |
| `episode_template.py` | 편 설계도 뼈대 |
| `get_fonts.py` | 글꼴 받기 |
| `tts.py` | N 마디 문구로 나레 합성 |
| `reframe.py` | 얼굴을 찾아 구간마다 크롭을 다시 잡는다 → `reframe.json` (§17-17) |
| `cutsheet.py` | 나레 컷을 한 장에 모아 눈으로 훑는다 |
| `dlgcheck.py` | 자막 없는 말이 없는지 본다 (**0개여야 굽는다**) |
| `build.py` | 굽기 + **규격 검사** + 설명문 초안 |

★`pan.py`(줌·팬)와 `sfx.py` 는 **없다.** 포레이로는 화면을 움직이지 않는다(§17-5).

완성본은 `volcano_work/포레이로/` 로 모인다. **완성본 하나만 건넨다.**

## 3. ★이야기 만드는 법 — 여기부터가 진짜다

화면 규격만 맞춰도 소용없다. **이야기가 안 되면 무슨 말인지 모르는 영상이 나온다.**
아래는 원본 두 편(2,865,212회 · 1,532,073회)의 자막을 순서대로 옮겨 뽑은 공식이다.

### 3-1. 나레이션은 해설이 아니라 **중계**다

원본 나레는 전부 **지금 화면에 보이는 것**을 말한다. 배경 설명도, 감상도 없다.

```
(시체 더미 화면)      조선인을 상대로 / 생체실험을 하던 / 마루타 부대에 / 퇴각명령이 떨어지고
(자료 태우는 화면)     생체실험을 한 / 증거를 없애기 위해 / 소각하는데
(학살 화면)           모든 조선인들을 / 학살시키고 / 시체들을 모아 / 한번에 소각시키려는
```

★**그래서 순서가 거꾸로다: 컷을 먼저 고르고, 그 컷을 보고 나레를 쓴다.**
   나레를 먼저 쓰고 그림을 갖다 붙이면 반드시 어긋난다(실제로 그렇게 만들었다가 다 뒤엎었다).

### 3-2. 일곱 칸 공식

| 칸 | 하는 일 | 원본 보기 |
|---|---|---|
| ① 상황 못박기 | 누가·어디서·뭘 하던 중·무슨 일이 터졌는지 **한 문장** | 조선인을 상대로 생체실험을 하던 마루타 부대에 퇴각명령이 떨어지고 |
| ② 인물의 말 | 그 사건을 **당사자 입으로**. 짧고 세게 | 48시간 안에 모든 퇴각 준비를 끝낸다 |
| ③ 그래서 어떻게 | 행동 | 증거를 없애기 위해 소각하는데 |
| ④ 인물의 말 | **강도를 한 단계 올린다** | 우리가 여기서 했던 그 어떤 것도 흔적으로 남기지 않는다 |
| ⑤ 결과 = 이 편의 그림 | 가장 센 장면 | 모든 조선인들을 학살시키고 시체들을 모아 한번에 소각시키려는 |
| ⑥ 마지막 행동 | 마무리 동작 | 실험체를 뒤로 한 채 전부 불에 태워버리죠 |
| ⑦ 여운 | **연결어미로 끊는다** | 자료들만 일부 챙긴 뒤 본국으로 돌아가는데 |

**점층이 재미의 원천이다.** 명령 → 증거인멸 → 학살 → 소각 → 유유히 귀국.
칸이 넘어갈수록 세져야 한다. 평평하면 지루하다.

### 3-3. 떡밥-회수 편은 이렇게 (신병4 같은 것)

원본은 점층형이지만, **모순을 던지고 답을 주는** 편도 같은 뼈대로 짤 수 있다.

```
0초   모순을 그림으로 던진다      (진흙탕에서 A급 전투복 입고 삽질)
①    그 모순을 말로 못박는다      "수해복구 현장에 제일 좋은 전투복을 입고 온 이중대"
②    누가 시켰는지 (대사)         "전원 A급 전투복으로 환복하시기 바랍니다"
③    ★질문을 대놓고 던진다        "작업하러 가면서 왜 좋은 옷이냐며 아무도 이해 못 했고"
④    반전 (대사)                 "이거 그냥 생짜배기 수해복구 현장이잖아"
⑤    갈등 고조                   "새 전투복이 흙탕물에 젖어가자 원망만 쌓이던 그때"
⑥    전제 → 답 (대사)            "작업복이면 일손이지만 군복을 갖춰 입으면"
                                → "국가가 약속한 안전 그 자체가 되는 거다"
⑦    여운                        "진흙탕 한가운데서 가슴이 뻐렁쳐버리는데"
```

★**질문을 시청자에게 대놓고 던져라.** "이상한 지시가 하나 더 붙는데" 같은 말로는
  왜 이상한지 모른다. **"진흙탕 가는데 왜 제일 좋은 옷이냐"** 처럼 모순을 말로 찍어야 한다.


### 3-5. ★나레이션 문체 — 토메이로 8편(230만~692만) 실측

사용자가 준 300~700만짜리 8편을 뜯었다. **문장력이 조회수를 가른다.** 규칙 여섯 개다.

**① 첫 줄이 상황을 한 방에 세운다** (제목의 확장)
```
훈련을 마치고 집에 가던 중 양아치들을 발견했는데        (331만)
몰래 게임하다 소리 질렀는데 관심 끄고 직원을 혼내는 사장  (587만)
해성이 샤워 중인데 밥을 가지러 온 준                   (692만)
```

**② 나머지 나레는 극도로 짧다 — 3~12자의 이음새**
`그 순간` · `일단 한대 맞고` · `몸치라고 혼나고` · `혼자 쇼를 하더니` · `헛소리를 하더니`
→ 나레가 설명하지 않는다. **장면을 넘기기만 한다.**

**③ ★같은 꼴을 반복해 리듬을 만든다 — 이게 몰입감의 정체다**
```
일단 한대 맞고 / 몸치라고 혼나고 / 피 같은 용돈을 내면서 / 핀잔도 들었지만 열심히 연습한 그녀
    ~고            ~고               ~면서                   ~지만
```
짧은 마디를 같은 어미로 연달아 던지면 속도가 붙는다. 길고 다른 꼴로 쓰면 늘어진다.

**④ 화자가 논평한다. 중립 해설이 아니다**
`혼자 쇼를 하더니` · `헛소리를 하더니` · `과감하게 20분을 지각해`
→ 냉소적인 친구가 옆에서 중계하는 말투다.

**⑤ 구어체로 쓴다**
"작업하다 옷만 버린다는 말이 돌았지만"(X) → **"작업하다 다 버릴 텐데"**(O)

**⑥ 끝맺음은 채널마다 다르다**
- 포레이로: `~돌아가는데` 로 **끊는다**(결말 안 줌)
- 토메이로: `바로 할 일을 하러 갑니다` · `그렇게 연습한 성과를 보여줄 시간이었죠` — **존댓말로 맺는다**
→ 뭉클하게 닫을 편은 토메이로식으로 맺는 게 낫다.

★대사 비중도 다르다. 토메이로는 **대사가 본문, 나레가 이음새**다.
  포레이로는 반대(나레 65%+). 소재가 대사로 웃기는 것이면 토메이로 쪽으로 기울여라.


### 3-6. ★마무리로 감동을 끌어내는 법 (사용자 확인 완료)

나레가 "그렇게 ~가 됩니다" 하고 요약하면 **감동이 안 온다.** 요약은 시청자가 이미 본 것을
되풀이하는 것뿐이다. 감동은 **인물의 입에서 나와야** 한다.

**틀린 마무리** (요약)
```
[대사] 국가가 약속한 안전 그 자체가 되는 거다
나레   진흙투성이가 된 이중대가 그렇게 구원군이 됩니다     ← 대사를 되풀이한다
```

**맞는 마무리** (나레가 받침 → 인물이 못박음 → 나레가 감정만 짚음)
```
나레   작업복이면 그냥 일손일 뿐이지만          ← 전제
[대사] 국가가 약속한 안전 그 자체가 되는 거다    ← 1차 답
나레   그러니까 지금 이 진흙탕에 서 있는 건       ← ★받침을 하나 더 깐다
[대사] 국가에서 보낸 가장 완벽한 A급 구원군이라는 말이다   ← ★진짜 펀치
나레   투덜대던 이중대의 어깨가 그제야 펴집니다   ← 감정만 한 줄, 요약 금지
```

**세 가지 규칙**
1. **펀치는 반드시 원본 대사다.** 나레로 감동을 설명하지 마라.
2. **펀치 직전에 나레로 받침을 깐다.** "그러니까 지금 이 ~는" 처럼 대사가 꽂힐 자리를 만든다.
3. **마지막 나레는 사건이 아니라 감정을 짚는다.** "어깨가 그제야 펴집니다" 처럼
   인물이 어떻게 변했는지 한 줄. 무슨 일이 있었는지 되풀이하지 마라.

★소재를 훑을 때 **가장 센 대사 두 개**를 찾아 둘 다 쓴다. 하나는 답, 하나는 펀치다.
  (전투복 편은 "안전 그 자체가 되는 거다" + "가장 완벽한 A급 구원군이라는 말이다")

### 3-4. 쓰기 전 자기 검사

1. **0초 그림만 보고** 무슨 얘긴지 궁금해지는가
2. 나레 한 마디씩 읽으면서 **그 순간 화면에 그게 보이는가**
3. 시청자가 **아직 모르는 정보를 나레가 먼저 말해버리지 않는가**
   (도착 전에 "진흙탕"부터 말하는 식 — 실제로 저질렀던 실수)
4. **결론이 전제보다 먼저 나오지 않는가**
5. 칸이 넘어갈수록 **세지는가**
6. 마지막이 연결어미로 끊기는가

## 4. 나레이션 원고 규격

원고가 곧 편집 설계도다. **원고를 먼저 쓰고 그림을 붙인다.** 반대로 하지 마라.

| 항목 | 값 | 실측 |
|---|---|---|
| 완성 길이 | **31~44초** | 31.3 / 36.8 / 38.7 / 38.9 / 40.4 / 43.3초 |
| 나레이션 총 글자수 | **200~380자** | 130~372, 중앙 172 |
| 나레이션 비중 | **65% 이상** | 상위 6편 49·66·79·83·85·93% |
| 초당 글자수 | **4.0~5.5자** | 3.95~5.35 (상위편) |
| 마디 개수 | **10~15개** | 9~15 |
| 마디 간격 | **2.7~3.8초** | 새 자막이 이 주기로 넘어간다 |
| 원본 대사 | **2~6번만** | 2·3·3·3·5·6 |

### ★문장을 끝내지 않는다

모든 마디를 연결어미로 잇는다. 실제 한 편(2,865,212회)의 전체 흐름:

```
~떨어지고 → ~소각하는데 → ~학살시키고 → ~일본군이었고
→ ~찰라 → ~태워버리죠 → ~돌아가는데          ← 여기서 끝난다
```

쓰는 어미: **-고 / -는데 / -이었고 / -지만 / -하며 / -자 / -죠**

### ★마지막도 연결어미로 끊는다

세 편이 `~돌아가는데` `~쓰러지는데` `~죽여버리는데` 로 끝난다.
**결말을 주지 않는다.** 완결된 문장으로 끝내면 이 프리셋이 아니다.

### 시점

3인칭 해설. **명사로 인물을 지목**한다 — "~하는 일본군이었고", "감탄하는 가토 중좌".
"그는", "그녀는" 같은 대명사를 쓰지 않는다.

## 4. 제목 두 행

1행 살구색(#F7B08D) · 2행 흰색. **1행이 수식·조건절, 2행이 주어(인물·집단)** 이고
**전체가 명사구로 끝난다.** 서술어로 끝내지 마라.

```
괴물 실험을 위해 희생된   /  마루타 부대의 조선인들
실험에 성공한 괴물을 보자  /  여신이라며 감탄하는 가토중좌
괴물이 뿜어내는 탄저균을   /  맞고 쓰러지는 조선인들
도가 지나치는 실험에      /  충격을 먹은 사치모토 류
힘든 속사정을 얘기 했지만  /  패드립을 갈기는 장태상
```

★줄바꿈은 **두 행 길이를 비슷하게** 맞추려고 하는 것이지 의미 단위가 아니다.
조사 한가운데서 끊어도 된다("탄저균을 / 맞고").

★유튜브 제목은 `화면 제목 + " #작품명"` 이다.

## 5. 컷 — 앞만 빠르다

```
0.0 ~ 5.0초   4~6컷, 한 컷 0.3~1.0초    난사
5.0초 ~ 끝     한 컷 1.0~3.0초           본문
```

- 전체 분당 **38~47컷**, 평균 컷 **1.23~1.49초**, 1초 미만 컷이 **31~56%**
- **★0초 프레임은 그 편에서 가장 센 그림이다.** 시간 순서를 무시하고 맨 앞에 놓는다.
  실측: 조회수 상위편 0초 = 시체 더미 · 피 튄 감옥 · 비명. 하위편 0초 = 평범한 인물 얼굴.
  **이 한 칸이 조회수를 가른다.**
- **줌·팬을 넣지 않는다.** 초당 배율변화 중앙값이 0.000~0.005 로 사실상 정지다.
  (딸기우유의 `pan.py` 를 여기서 쓰지 마라 — 다른 채널 규격이다)

## 6. 자막 두 계층

| | 색 | 잉크높이 | 자리 | 쓰는 곳 |
|---|---|---|---|---|
| 대사·나레 | 흰색 #FFFFFF | 85 | 중앙 y **1205** | 나레이션과 평범한 대사 **둘 다** |
| 효과자막 | 분홍 **#FD91D8** | 97 | 같은 자리 또는 그림 위쪽 | 감탄·비명·의성어·결정적 대사 |

- 둘 다 **검은 테두리 13px**(글자높이의 15%), 같은 글꼴
- 한 줄 **11자까지**(폭 1000px). 넘으면 2행. 2행이면 어절 단위로 끊는다
- 나레이션에도 자막을 붙인다. **색으로 나레와 대사를 가르지 않는다** — 흰색 하나다
- 효과자막은 편당 **2~5개**(분당 4~7). 0초에 얹는 편이 10편 중 5편
