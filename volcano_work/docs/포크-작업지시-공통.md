# 포크 공통 작업 지시 (포레이로 · 2026-09-19)

한 포크는 편 하나만 만든다. 커밋·푸시는 하지 않는다(부모가 한다). 다른 mk* 폴더는 건드리지 않는다.

## 절차 (PowerShell · `$env:PATH="$HOME\.volcano\venv\Scripts;$env:PATH"` · cwd `~/volcano_work` · `$P="presets\포레이로"`)

1. 전편 전사 `epN_scan/lines.txt` 에서 장면 구간을 먼저 읽는다. `python $P\prep.py <편폴더> "<소재>" <start> <end>` — 마지막 센 대사 뒤 **~8초 꼬리**를 붙여 닫는 나레 자리를 만든다(§17-50). `_peek`/`epN_scan/map_*.jpg` 로 구간·화자를 확인한다.
2. `epN_scan/asr_epN.json` 의 words(`word/start/end`)를 offset=start 로 잘라(구간 [start,end)) gap>0.6초로 segments 를 묶어 `<편폴더>/asr_ko.json` {segments, words} 로 쓴다. 일본어·웅얼거림·불확실 낱말은 D 블록 밖(나레 밑) 또는 ≤1초 덮기.
3. `episode.py` 는 **`~/volcano_work/mk13c_나레줄임/episode.py`(비중 기준 편 · 말투는 mk13b)** 를 끝까지 읽고 그 꼴로 쓴다 — 머리 docstring(국면 지도·말하는 이·전사 교정), `spec.DLG_TAIL=0.30 / NARR_PAD=0.04 / TTS_TEMPO=1.3`, `STYLE="tome"`, `HEAD1/HEAD2` 각 ≤12자, `BLOCKS`(N 5~6마디 그림 직접지정 + D 10블록 안팎), `CUTS`=첫 N 의 컷, `EFFECTS=[]`.
4. `dlgcheck.py <편> <편>\asr_ko.json 0`(자막 없는 말 0) → `get_fonts.py` → `tts.py` → `align.py` → `reframe.py` → `build.py`(**분당 컷<35 빼고 [규격 위반] 전부 고친다**) → `synccheck.py`(≤0.10초) → `cutsheet.py` 후 **cutsheet.jpg 를 Read 해서 컷의 화자·장면이 맞는지 눈으로 확인**(틀리면 고친다).
5. 납품: `~/Downloads/드라마/<편>.mp4` + `~/volcano_work/포레이로/<편>_업로드.txt`(→ Downloads 에도 복사) + `~/forey-preset/volcano_work/examples/<편>/` 에 episode.py·업로드.txt 복사.
   업로드 세트는 `포레이로/mk13b_촌평_업로드.txt` 꼴 그대로: 제목 줄 "HEAD1 — HEAD2 #메이드인코리아2" / 빈 줄 / 설명 2~3문단(센 대사 인용, 욕설·뽕은 X) / 빈 줄 / `* 작품: 메이드 인 코리아 2` / `더 자세한 내용은 디즈니 플러스에서 감상하는 걸 추천합니다!` / 빈 줄 / `#메이드인코리아2`.

## 나레 말투 (부록 M-1~15 · 전부 필수)

- ★**비중(부록 M-16, 2026-09-19 확정)**: 나레 **5~6마디 · 마디 ≤18자 · 편당 60~90자 · 시간 20~25%**. 대사 **10블록 안팎 · 시간 70% 이상** — 짧은 반응도 D 로. **나레 두 마디 연속 금지**(사이에 대사). 기준 편 `mk13c_나레줄임/episode.py`.
- 3인칭 · 과거 · 존댓말 **한 문장 10~18자**, 한 마디 한 정보. 어미는 `~죠`(맺기) / `~는데`(넘기기) **둘뿐** — `~기에` ✗, `~다/~습니다` ✗, `~데?` ✗, `|` ✗.
- 인물은 **이름·자신·그·그녀·관계어(형/동생/누나/오빠)** — **직함·신분 ✗**(부장·중령·검사·고문·실장·생도·사령관·총장 …). 대사 자막의 직함은 들리는 대로 둔다. 성만 알려진 인물(곽실장 등)은 "곽" + 관계어("각하 곁의 곽")로 피하고, 정 안 되면 한 번만 쓰고 보고에 적는다.
- **쉬운 말만**: 요정→술집, 실행 여부→시작할지, 묵비권→입 다물기, 정통성→명분, 비자금 장부→돈 장부.
- 나레는 대사를 되풀이하지 않는다 — 이유·심리·결과만. 샌드위치(나레→대사→나레).
- **마지막 마디만 반말 촌평, 주인공을 까지 않고 주인공 입장에서**("동생이 폭탄 위에 앉았으니 기태는 피가 마르겠네").
- 욕설 자막은 X 가림(씨X·개X끼), **'뽕'은 자막 X쟁이/X, 나레는 '약'**. 물음표는 질문에 반드시.
- 자막 폭 ≤1010px → 한 줄 ~13자에서 나눈다. D 블록 = 첫 낱말−0.08 ~ 마지막 낱말+0.30.

## 컷

컷 합 ≈ 마디 길이 — **짧은 마디(≤2.5초) 1~2컷**, 3초 넘는 마디만 3컷. 나레 컷은 [앞 대사 시작−3, 뒤 대사 끝+3] 안(0초 훅 제외). 컷 ≥0.28초. 0초 프레임 = 그 편에서 가장 센 그림(고문·유혈 ✗). 완성 **40~50초**. 고문·구타 본장면은 컷에 넣지 않는다(얼굴·손·문·반응만).
