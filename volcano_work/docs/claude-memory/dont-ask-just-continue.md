2026-09-09 사용자가 못 박았다: **"응 묻지말고 앞으로는계속해"**

일이 한 덩이 끝날 때마다 "이어서 갈까?"라고 묻지 마라. 다음 단계가 분명하면 그냥 한다.

**Why:** 이 세션에서 단계마다 확인을 받으려다 진행이 계속 끊겼다. 사용자는 결과물을
원하지, 진행 여부에 대한 승인 요청을 원하지 않는다. 같은 맥락에서 사용자는
원본 찾기에 헤맸을 때도 "잘 좀 해"라고 지적했다 — 물어보는 대신 스스로 방법을 바꿔야 한다.

**How to apply:**
- 다음 단계가 하나로 정해지면 **바로 실행하고**, 끝난 뒤에 결과만 보고한다.
- 갈림길이 여럿이고 결과가 크게 달라질 때만 묻는다(예: 소재를 무엇으로 할지).
- 되돌리기 어렵거나 바깥으로 나가는 일(업로드·공개·삭제)은 여전히 확인받는다.
- 막히면 묻지 말고 방법을 바꿔서 다시 시도한다. 텍스트 검색이 안 되면 프레임을 보는 식.
