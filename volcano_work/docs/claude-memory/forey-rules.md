## ★★먼저 읽어라

**`docs/포레이로-지침서.md`** — 사용자가 못 박은 것 **전부**를 한 문서에 모아 고정했다.
포레이로 편을 만들기 전에 **처음부터 끝까지 읽는다.** 아래는 그 요약이다.

포레이로 편을 만들 때 **매번 이대로 한다.** 사용자가 하나씩 지적해 쌓인 것이고,
2026-09-06 에 "이 정도로 맞춰주면 좋겠다"고 확인받은 상태다. 수치는 `presets/포레이로/spec.py`.

## ★0순위 — 싱크

**가장 기본은 싱크다.** 말과 자막이 어긋나면 나머지는 다 소용없다. 사용자가 여러 번 지적했다.

- 대사 시각은 **단어 하나하나** 전사로 받아 잡는다. 묶음으로 뭉뚱그리면
  그 안에 **자막 없이 들리는 말**이 생긴다(실제로 10초에서 그랬다)
- `dlgcheck.py` 로 **자막 없는 말이 0개**인지 확인하고 나서 굽는다
- 나레 자막은 `align.py` 로 실제 발화 시각에 붙인다
- 절차: `prep → 대사구간 전사 → episode.py → **dlgcheck(0개)** → get_fonts → tts → align
  → **reframe** → build → **cutsheet 눈검사**`

**전사 시각은 믿되, 전사 글자는 믿지 마라.**
소리 나는 대로 받아써서 글자가 틀린다. 시각은 그대로 두고 **글자만** 고쳐 자막에 넣는다.
걸렸던 것: 대장님께→**대대장님께** · 장 못 딴 겁니까→**장 못 담급니까** ·
윤재→**윤윤제** · 까페→카페.

**효과자막은 그 말이 나온 뒤에.**
아직 아무도 안 한 말을 효과자막이 앞질러 뱉으면 무슨 소린지 모른다.
("부대 카페요?" 를 1초에 띄웠다가 지적받았다.) `build.py` 가 검사한다.

## ★★컷 고르기 — 사용자가 세 번 지적한 것 (2026-09-06)

> "왜 영상이랑 상관없는 것들이 섞이는 거야!!"
> "이거 내가 일일이 다 찾아서 말해야 되니"

**시각만 보고 컷을 고르지 마라. 프레임을 눈으로 보고 골라라.**
`cutsheet.py <편폴더>` 로 컷을 한 장에 모아 **굽기 전에** 훑는다.

1. **한 마디의 컷은 전부 같은 국면(장소·시점)에서 고른다.**
   실내 이야기를 하는 마디에 야외 그림을 섞지 마라. (ep03 에서 지적받았다)
2. **국면 순서대로 간다.** 실내 → 이동 → 현장. 마디가 말하는 시점보다 앞선/뒤진 그림을 쓰지 마라.
3. **특정 장면 전용 그림은 그 마디에만.** ep02 의 손 맞잡는/손가락 약속 그림은 **망상 마디에만** 쓴다.
   딴 마디에 깔면 "왜 손이 또 나와" 소리를 듣는다.
4. **손·팔을 치켜드는 동작**은 맥락 없이 보면 때리는 것처럼 보인다. 피해라. (ep16)
5. **한 shot 을 조각내 여러 마디에 뿌리지 마라.** 되풀이로 보인다. (ep15 고양이)
6. **모션블러·초점 나간 프레임**은 컷 가운데 시각을 옮겨 피한다. 0초 프레임은 특히.

**고르는 방법** — 소재를 1~1.5초 간격으로 통째로 떠서 지도(map)를 만들고,
어느 구간이 어느 국면인지 적어 둔 다음 마디마다 그 국면에서만 뽑는다.

## 절대 규칙 (어기면 다시 만든다)

1. **★대사는 절대 잘리지 않는다.** 대사가 끝까지 나오고 → 그다음에 나레가 붙는다.
   오디오가 잠깐 비는 건 참아도 대사가 잘리는 건 안 된다. 엔진이 대사 뒤 여유를
   자동으로 확보하고(램프+0.14초), 모자라면 경고한다.
2. **대사 구간은 눈대중 금지.** 그 구간을 전사해 **단어 시각**으로 잡는다.
   (눈대중으로 잡았다가 세 대사가 전부 말 한가운데서 잘렸다)
3. **나레 자막은 `align.py`** 로 실제 발화 시각에 붙인다. 글자수 비례·파형 골짜기는 어긋난다.
4. **말과 그림이 따로 놀면 안 된다.** 마디마다 `("N", "문구", [(컷)…])` 로 그림을 직접 붙인다.
5. **같은 장면을 두 번 쓰지 않는다.** 컷이 모자라면 되풀이 말고 **느리게 늘려** 채운다.
6. **이름·고유명사를 잘라먹지 않는다.** (남편은 윤재 X → **윤윤제** O)

## 목소리·속도

- 타입캐스트 **SeHee**(`tc_611c3f692fac944dff493a04`) · **1.2배속**
- 원본 대조: 토메이로 F0 225Hz / 14자 1.76초 ↔ SeHee 1.2배 246Hz / 1.88초

## 글자

- 제목·대사·효과자막 = **그리운 코코초이툰** / 나레 = **도현체**
- 나레 = 살구 #FFD2B2 · 1행 · 위(y1075) / 대사 = 순백 · 아래(y1272)
- 크기는 **캡컷 기준**으로 말한다. `잉크px ≈ 캡컷크기 × 5.6`. 나레 13 · 대사 14 · 효과 10
- **나레도 대사도 4~10자 덩이로 잘라 순서대로 넘긴다**
- 숫자+단위를 갈라 쓰지 않는다 (냉동식품 만 / 원어치 X)
- 질문하는 대사에는 **물음표**를 넣는다
- 애니메이션: **52%로 작게 나타나 100%로 커진다**(125ms)
- 아래 띠에 **작품명**을 흰색·글자높이 64·y1563 으로 넣는다 (토메이로 방식)

## 소리

- 나레 구간은 원음을 **통째로** 끈다. '말하는 동안만' 끄면 마디 사이로 드라마 소리가 샌다
- 끄는 시점은 나레 블록 **시작 전**. 안 그러면 나레 앞머리에 대사가 찔끔 터진다
- 장면전환 효과음(whoosh)은 **이음매 앞뒤 프레임을 실제로 비교**해 확 바뀌는 곳만.
  '마디 바뀔 때' 같은 어림으로 깔면 남발이 된다. 한 편에 최대 6개

## 이야기 (README 3장)

- **나레는 해설이 아니라 화면 중계다.** 컷을 먼저 고르고 그 컷을 보고 나레를 쓴다
- 시청자가 **아직 모르는 정보를 나레가 먼저 말하지 않는다**
  (병사들은 수해복구인 줄 모른다 — 도착해서야 안다)
- 문체(토메이로): 첫 줄로 상황 한 방 → **3~12자 이음새를 같은 꼴로 연달아**(리듬)
  → 화자가 논평 → 구어체
- **★마무리**: 나레가 받침을 깔고 → **인물의 대사가 펀치** → 나레는 감정만 한 줄.
  요약하면 감동이 안 온다. 소재에서 **가장 센 대사 두 개**를 찾아 답과 펀치로 쓴다

## ★2026-09-07 에 새로 박은 것 (사용자가 세 번 지적)

1. **"말할 때 그 화자가 얼굴 보이게 만들어… 화면 안에 잘 배치해봐"**
   → `reframe.py` 를 굽기 전에 돌린다. [[forey-reframe]]
2. **"왜 자꾸 장면 중에 다른 장면이 들어가니 / 물음표 넣으라고 했잖아.
   내가 말한 거 다 메모하고 박으라고 했는데 왜 그게 반영이 안 돼?"**
   → 지침서에만 적혀 있고 **엔진이 검사를 안 해서** 매번 샜다.
   **적어 두는 것만으로는 안 지켜진다 — 검사로 박아야 지켜진다.**
   `build.py` 가 물음표·나레 컷 자리를 막는다. `scan.py` 로 전 편을 훑는다.
3. **"효과자막이 영상이랑 안 맞아. 그렇게 안 맞게 할 거면 차라리 없애버려"**
   → 효과자막 자리를 완성본 초로 눈대중했더니 두 장이 영상 밖으로 나가고
   나머지는 엉뚱한 얼굴에 붙었다. **마디에 건다**: `(("D", n, 0.15), …)`.
   `fxscan.py` 로 전 편을 훑는다.

## ★2026-09-15 사용자 나레 문체 (mk02)

- **「~하는 [인물]」 명사구**로 장면을 찍는다: "각하의 집무실에 불려오는 중정 차장 백기태" · "그때 손님을 안내하는 비서" · "신여사를 처음 보는 백기태".
- 사이사이 **"~는데?" · "~고"** 로 잇고, 상황에 **"개빡친"** 같은 구어 양념을 넣는다. 인물은 반드시 **이름**으로.
- 마지막 멘트는 사용자가 정한 "내 생각" 한 줄(예: "역시 잘생기면 끝이네요" · "넘버투 어쩌고 하더니 눈빛 한 방에 열라 쫄았네").
- 대사는 살리고 나레는 말틈에 짧게(`STYLE="tome"`), 목소리는 커스텀 "드라마" 1.3배.
