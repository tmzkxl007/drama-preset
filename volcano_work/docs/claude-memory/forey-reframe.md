포레이로 편을 굽기 전에 **반드시** `python presets\포레이로\reframe.py <편폴더>` 를 돌린다.
tts·align 다음, build 앞이다.

**Why:** 16:9 원본에서 가운데 1150px 만 잘라 세우기 때문에 좌우 끝에 선 사람은 얼굴이 통째로
날아가고, 넓은 shot 은 사람이 콩알만 해진다. 사용자가 s2ep5·s2ep6 을 보고
"말할 때 그 화자가 얼굴 보이게 만들어, 너무 얼빡 안 해도 되고 화면에 두 사람이 나올 수도 있잖아,
화면 안에 잘 배치해봐" / "6번도 다시 화자가 중앙에 배치하게 수정해" 라고 못 박았다.

**How to apply:** 자동이 틀리면 `episode.py` 의 `CROP_SHOT = [(시작,끝,중심x,중심y,폭배율)]` 이 이긴다.
**원본이 캄캄하거나 화면에 아무도 없으면 크롭으로 못 고친다 — 그 컷을 버리고 다른 컷을 골라라.**
피할 수 없는 대사 구간만 `LIFT_AT = [(시작,끝,세기)]` 로 걷어올린다.
자세한 것은 [[forey-rules]] 가 가리키는 `docs/포레이로-지침서.md` §12-2 와 `PLAYBOOK` §17-17.
