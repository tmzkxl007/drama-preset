# 포레이로 지침서 — 사용자가 못 박은 것 전부

> **이 문서가 최우선이다.** 포레이로/토메이로 편을 만들기 전에 **반드시 처음부터 끝까지 읽는다.**
> 규격 수치는 `presets/포레이로/spec.py`, 실측 근거는 `docs/PLAYBOOK.md` §17.
> 2026-09-05 ~ 09-06 사이에 사용자가 하나씩 지적해 쌓인 것이다. **추측으로 바꾸지 마라.**

## 0. 순위

무엇을 포기하더라도 **위에서부터** 지킨다.

| 순위 | 무엇 | 사용자의 말 |
|---|---|---|
| **1** | **싱크** — 말과 자막이 맞을 것 | "제대로. 가장 기본은 씽크 맞추는 거야" |
| **2** | **대사를 자르지 않을 것** | "절대 대사 잘라먹지 말고 기본적으로 세팅해놔" |

## 1. 소재 — 손대면 안 되는 것

- **불법 스트리밍 사이트에서 받은 파일은 쓰지 않는다.** (누누티비 등)
  사용자가 "저작권 구매했다"고 해도 **그 파일**로는 만들지 않는다. 공식 클립이나
  사용자 본인 파일을 받아서 만든다.
- 남의 채널 영상이면 **사용 권한을 사용자에게 확인**한다.
- 출입증(`.volcano_runner_key.json`)·API 키·미디어 파일은 **절대 커밋하지 않는다.**

## 2. 한 번에 한 프리셋만

> "섞지마 너는 포레이로만 하는거야 정신차려"

작업 중인 프리셋에 **다른 채널의 소재·엔진·습관을 끌어오지 않는다.**
딸기우유의 `pan.py`(줌·팬), 딸기우유의 노랑 나레 — 여기서 쓰지 마라.

## 3. 내보내기

> "완성본만 내보내기해줘"

- **완성본 영상 하나만 건넨다.** 중간 파일 목록을 늘어놓지 마라.
- 완성본은 `볼케이노_work/포레이로/` 에 모인다.
- 작업이 한 덩이 끝나면 `docs/PLAYBOOK.md` 에 규칙을, `docs/SESSION-LOG.md` 에 이력을
  더하고 **커밋한다.** (사용자가 "최상위 강제 규칙"이라고 못 박았다)

# 제1부 · 싱크 (0순위)

## 4. 절차 — 순서를 바꾸지 마라

```
소재 자르기 → 그 구간 전사(단어 시각) → episode.py 작성
→ dlgcheck   ★자막 없는 말 0개 확인
→ get_fonts → tts → align
→ reframe    ★화자를 화면 안에 넣는다 (§17-17)
→ build
→ synccheck  ★★씽크를 **재서** 확인한다 (0순위 — 아래)
→ cutsheet 로 컷 눈검사
```

**★★씽크는 재서 확인한다. 눈대중·"맞겠지" 금지.**

```
python presets/포레이로/synccheck.py <편폴더>
```

원본 소리 크기 곡선을 완성본에서 찾아 **몇 초 어긋났는지 숫자로** 찍는다.
**0.10초를 넘으면 씽크가 깨진 것이다.**

한 번 크게 당했다(2026-09-09): 소재가 30fps 인데 컷마다 `trim` 이 프레임 경계로 올림돼
**컷 하나에 최대 1프레임씩 길어지고, 35컷이면 0.3초가 쌓여** 뒤로 갈수록 자막·나레가 밀렸다.
→ 이제 `build.py` 가 **모든 길이를 1/FPS 격자에 맞추고, 굽을 때 프레임 수로 못 박는다.**
그 전에 구운 편은 **전부 다시 구워야 한다.**

## 5. 대사 시각은 전부 **단어 시각**

- 눈대중 금지. 그 구간을 `_asr_sm.py` 로 전사해 **단어 하나하나의 시각**을 받는다.
- `episode.py` 의 D 블록은 `[(글, 말시작, 말끝), ...]` 로 적는다.
- `dlgcheck.py <편폴더> <전사.json> <보정초>` 가 **"자막 없는 말 0개"** 여야 굽는다.
  보정초 = 전사시각 − 소재시각.
- ★함정: `src_0905/asr.json` 처럼 **원본 전체 시각**으로 된 전사가 있다. 보정초를 확인해라.

## 6. 대사는 절대 잘리지 않는다

> "대사가 다 끝나기도 전에 나래이션이 나와" / "오디오 비는 것도 안 좋지만 대사가 잘리는 건 더 절대 안 돼"

- 대사가 **끝까지** 나오고 → 그다음에 나레가 붙는다.
- **D 블록은 말이 쉬는 자리에서만 끊는다.**
  `마지막말끝 + 0.34초(DLG_TAIL) < 다음말시작` 이 성립하는 자리만 경계로 쓸 수 있다.
  0.03초밖에 안 비는 자리에서 끊으면 자동연장이 다음 말을 물어 **말이 잘린다.**
- 끊을 자리가 없으면 **통으로 둔다.** 대신 나레 마디를 늘려 비중을 맞춘다.
- 말끝에 붙는 짧은 대답("예", "예 맞습니다")도 **말이다.** 자막을 달거나 블록 밖으로 뺀다.

## 7. 나레 자막은 `align.py`

글자수 비례·파형 골짜기로 나누면 자막이 말보다 앞선다. 나레 wav 를 전사해 **단어 시각**으로 붙인다.

# 제2부 · 글자

## 8. 전사 시각은 믿되, **전사 글자는 믿지 마라**

소리 나는 대로 받아써서 글자가 틀린다. **시각은 그대로 두고 글자만** 고쳐 넣는다.

| 전사 | 실제 |
|---|---|
| 저 **대장님**께 | 저 **대대장님**께 |
| 장 못 **딴** 겁니까 | 장 못 **담급니까** |
| 남편은 **윤재** | 남편은 **윤윤제** (성을 자르지 마라) |
| **방민호** | **박민석** |
| **성병** 점검 | **소등** 점검 |
| **불침만** | **불침번** |
| **생짜바리** | **생짜배기** |
| **입금을** 입힌 | **A급을** 입힌 |
| **노래** 없이 | **예외** 없이 |
| **저는 에이급** | **전원 A급** |
| **한복**하시기 | **환복**하시기 |
| **지사장**으로 | **지시사항**으로 |
| **묻고** | **먹고** |
| 까페 | 카페 |

**★글자를 확신할 수 없으면 자막에 올리지 않는다.**
그 대목을 D 블록 밖으로 빼거나, **앞 자막의 시각만 늘려** 덮는다(글자는 안 쓴다).

**★덮는 것도 1초까지다.** 흐린 말을 앞 자막으로 오래 덮으면
**지나간 자막이 화면에 남아 밀린 것처럼 보인다**(사용자: "씽크 안 맞아").
1초를 넘길 상황이면 **덮지 말고 그 자리를 대사 블록에서 빼라.**
`build.py` 가 3.2초 넘게 떠 있는 대사 자막을 규격 위반으로 막는다.

## 9. 자막 규격

| | 색 | 잉크높이(캡컷) | 자리 | 글꼴 |
|---|---|---|---|---|
| 제목 1행 | 살구 #F7B08D | 95 | y204 | 그리운 코코초이툰 |
| 제목 2행 | 흰색 | 92 | y315 | 그리운 코코초이툰 |
| **나레** | **살구 #FFD2B2** | **73 (캡컷 13)** | **y1075** | **BM 도현체** |
| **대사** | **순백** | **78 (캡컷 14)** | **y1272** | **그리운 코코초이툰** |
| 효과자막 | 분홍 #FD91D8 | 56 (캡컷 10) | 그림 위쪽 | 그리운 코코초이툰 |

- 크기는 **캡컷 기준**으로 말한다. `잉크px ≈ 캡컷크기 × 5.6`
- **한 덩이는 15자 안쪽.** 16자부터 화면 밖으로 잘린다. 길면 시각을 쪼개 두 덩이로.

- 숫자+단위를 갈라 쓰지 않는다. (냉동식품 만 / 원어치 ✗)

  "봐야 할 곳"으로 찍어 준다 — 질문이면 붙여라. (사용자가 두 번 지적했다)
- 애니메이션: **52%로 작게 나타나 100%로 커진다** (125ms, fade 70/60)

## 10. 효과자막

- **자리는 마디에 걸어라.** `(("D", n, 0.15), "글자", "right")` = n번째 대사 블록이
  끝나고 0.15초 뒤. **완성본 초를 손으로 세지 마라** — 나레 길이는 굽기 전엔 모른다.
  실제로 두 편이 영상 밖으로 나가 아예 안 보였고, 나머지도 엉뚱한 얼굴 위에 붙었다.
  (사용자: **"효과자막이 영상이랑 안 맞아. 그렇게 안 맞게 할 거면 차라리 없애버려"**)
- **10자를 넘기지 마라.** 넘으면 두 줄로 접힌다. `build.py` 가 막는다.
- **그 말이 나온 뒤에만** 띄운다(§17-16). `build.py` 가 막는다.
- 굽을 때 `효과자막 '…' N초 → 소재 M초` 가 찍힌다. **국면 지도와 대조해서 확인해라.**
- ★★**자리는 대사 블록 안쪽에 건다** — `(("C", n, k, 0.05), "글자", "right")` =
  n번째 대사 블록의 **k번째 자막이 끝나고** 0.05초 뒤.
  `("D", n, dt)`(블록이 **끝난 뒤**)는 거의 항상 다음 나레 자리라
  **말한 사람이 화면에서 사라진 뒤에 뜬다.**
- 두 장이 한 화면에 같이 뜨면 규격 위반이다. `build.py` 가 막는다.
- ★★**톤이 안 맞으면 아예 빼라.** 사용자: **"양념자막을 할 거면 제대로 하고 안 되면 하지 마"**
  경성크리처(시대극·비극) 9편은 **0장**으로 간다. 분홍 양념자막은 코미디(신병) 것이다.
  `EFFECTS = []` 로 두면 된다 — 0장은 규격 위반이 아니다. 1장만 붙이는 게 위반이다.


- 편당 **2~5장**.
- **★그 말이 끝난 직후에 얹는다.** 아직 아무도 안 한 말을 앞질러 뱉으면 무슨 소린지 모른다.
  말하는 **도중**에 얹어도 안 된다 — 누가 하는 말인지 헷갈리고 상황과 겉돈다.
- `build.py` 가 검사한다. (효과자막의 낱말이 앞에는 없고 뒤에만 있으면 경고)

# 제3부 · 그림 (컷)

> "왜 영상이랑 상관없는 것들이 섞이는 거야!!" / "이거 내가 일일이 다 찾아서 말해야 되니"

## 11. 고르는 방법 — 이렇게 안 하면 또 섞인다

1. 소재를 **1~1.5초 간격으로 통째로 떠서** 국면 지도를 만든다.
2. 어느 구간이 **어느 국면**인지 적는다. (실내 / 이동 / 현장 / 자는 척 / 엿봄 / 다른 장면 …)
3. 마디마다 **그 마디가 말하는 국면에서만** 뽑는다.
4. 다 고른 뒤 `cutsheet.py <편폴더>` 로 한 장에 모아 **굽기 전에** 눈으로 훑는다.
   → cutsheet 는 **확인용**이지 고르는 도구가 아니다.

## 12. 컷 고를 때 지킬 것

1. **그 편 이야기 안에서만 고른다.** 다른 사건·다른 장소는 아무리 그림이 좋아도 안 쓴다.
2. **한 마디의 컷은 전부 같은 국면에서.** 실내 이야기를 하는 마디에 야외를 섞지 마라. (ep03)
3. **국면 순서대로 간다.** 실내 → 이동 → 현장. 마디가 말하는 시점보다 앞선/뒤진 그림 금지.
   ★`build.py` 가 검사한다 — 나레 컷은 **앞 대사가 시작한 곳 ~ 뒤 대사가 끝나는 곳** 안에
   있어야 한다(여유 3초). 0초 프레임만 예외(§13).
   사용자: **"왜 자꾸 장면 중에 다른 장면이 들어가니"** — s2ep5 에서 맨 앞 1~15초 장면을
   뒷마디에 끌어다 썼다. **자리가 모자라면 다른 데서 빌려 오지 말고 문구를 줄이거나
   그 마디를 대사 뒤로 옮겨라.**
4. **나레가 말하는 것과 화면이 같아야 한다.**
   "자는 척했다"는데 **고개를 들고 있으면 안 된다.** (ep07)
5. **특정 장면 전용 그림은 그 마디에만.** 망상 속 손 그림은 망상 마디에만. (ep02)
6. **손·팔을 치켜드는 동작**은 맥락 없이 보면 때리는 것처럼 보인다. 피해라. (ep16)
7. **한 shot 을 조각내 여러 마디에 뿌리지 마라.** 되풀이로 보인다. (ep15 고양이 4번)
8. **같은 장면을 두 번 쓰지 않는다.** 모자라면 되풀이 말고 **느리게 늘려** 채운다.
9. **모션블러·초점 나간 프레임**은 컷 가운데 시각을 옮겨 피한다. **0초는 특히.**
10. **마디마다 그림을 직접 붙인다.** `("N", "문구", [(시작,끝), ...])`

## 12-2. ★말하는 사람이 화면 안에 있어야 한다

> "말할 때 그 화자가 얼굴 보이게 만들어. 너무 얼빡 안 해도 되고
> 화면에 두 사람이 나올 수도 있잖아. **화면 안에 잘 배치해봐**"
> "글자 없고 화면에 사람이 없는 씬도 수정"

가운데 1150px 만 잘라 세우기 때문에, **좌우 끝에 선 사람은 얼굴이 통째로 날아간다.**
넓은 shot 은 사람이 콩알만 해진다. 굽기 전에 반드시 한 번 돌린다.

```
python presets\포레이로
eframe.py <편폴더>     # → reframe.json, build 가 읽는다
```

- 얼굴폭이 크롭폭의 **20%** 가 되게 잡는다. 얼빡은 아니고 표정은 읽히는 크기.
- **두 사람이 같이 들어와도 된다** — 살아남은 얼굴을 다 담고 양옆에 여백을 준다.
- 자동이 틀리면 `episode.py` 가 이긴다:
  `CROP_SHOT = [(시작, 끝, 중심x, 중심y, 폭배율), ...]`
- **★크롭으로 못 고치는 것**: 원본이 캄캄하거나 화면에 아무도 없으면
  **그 컷을 버리고 다른 컷을 골라라.** 피할 수 없는 대사 구간만
  `LIFT_AT = [(시작, 끝, 세기), ...]` 로 걷어올린다.
- 벽에 붙은 사진을 얼굴로 잡는 사고가 있었다 → 얼굴폭 5% 미만이거나
  샘플의 절반도 못 잡으면 **손대지 않는다**(엔진이 알아서 거른다).

## 13. 0초 프레임

- 시간 순서를 무시하고 그 편에서 **가장 센 그림**을 놓는다.
- 단, 그 그림이 **이야기와 어긋나면 안 된다.** 선명한 얼굴이 안전하다.

## 14. 컷 길이

- **컷 길이 = 마디 길이 ÷ 컷 개수.** 2초 마디에 3컷이면 0.65초씩.
- 엔진은 컷을 버리지 않는다 — 합이 길든 짧든 **배속만 바꿔 다 쓴다.**
- 한 컷이 **0.28초 아래로 내려가면 깜빡인다.** 그 마디는 컷 개수를 줄여라.

## 15. 어두운 소재

- 야간·소등 씬은 그대로 쓰면 0초 프레임이 죽는다 → `episode.py` 에 **`LIFT = 0~100`**.
  brightness 만 올리면 화면이 뜬다. `nightlift()` 는 **감마로 어두운 쪽만** 올린다.
  (야간 초소 65 / 소등 붉은 화면 35~45)

# 제4부 · 소리

## 16. 원음과 나레가 겹치지 않는다

> "자꾸 겹치게 만들지 마" / "떨어지고 사이에 튀는 소리 들려"

- 나레 구간은 원음을 **통째로** 끈다. '말하는 동안만' 끄면 마디 사이로 드라마 소리가 샌다.
- 끄는 시점은 나레 블록 **시작 전**(-0.09초). 안 그러면 나레 앞머리에 대사가 찔끔 터진다.
- 경계마다 0.07초 램프. 안 그러면 튀는 소리가 난다.

## 17. 장면전환 효과음

> "아무때나 남발하고 있어"

- **이음매 앞뒤 프레임을 실제로 비교**해 확 바뀌는 곳에만 넣는다.
- '마디 바뀔 때' 같은 어림으로 깔면 남발이 된다. **한 편에 최대 6개.**

# 제5부 · 이야기

## 19. 나레는 해설이 아니라 **화면 중계**다

> "새 전투복이 젖어들자 이런 나래이션이 있는데 영상에는 그런 영상이 없어"

> "나레이션이 대사를 따라하냐 나레이션이 이야기를 몰아가야지" (2026-09-09)

- **컷을 먼저 고르고, 그 컷을 보고 나레를 쓴다.**
- 시청자가 **아직 모르는 정보를 나레가 먼저 말하지 않는다.**
  (병사들은 수해복구인 줄 모른다 — 도착해서야 안다)
- **대사가 이미 던진 질문을 나레가 되풀이하지 않는다.**
- ★★**나레는 대사가 말하지 않는 것만 말한다** — 때·곳·관계·인물 이름·앞뒤 사정·결과.
  대사가 "건물을 무너뜨리지는 못해도"라고 했는데 나레가
  "건물을 무너뜨리지는 못한다고 했습니다"라고 받으면 **두 번 듣는 것**이다.
  `build.py` 가 앞뒤 대사와 **2글자 겹침 34% 이상**이면 규격 위반으로 막는다.
- ★★**인물은 이름으로 부른다.** "남자·여자·노인"이 아니라
  **장태상·윤채옥·나월댁·마에다 유키코**. 누가 말하는지 화면과 맞는지 확인하고 써라.
  (g25 에서 따지는 사람을 "구 사장"이라 썼는데 화면은 나월댁이었다)

## 20. 말이 되게

> "아무리 6초에 후킹이 있어도 말이 되게 만들어야지" / "몰입감 있게"

- 결론을 전제보다 먼저 놓지 마라.
- 인물이 모르는 것을 아는 것처럼 쓰지 마라.
- **드라마 숏폼은 나레이션이 다 끌고 간다.** 긴박하게, 감정을 끌고 가게.

## 21. 문체 (토메이로)

- 첫 줄로 상황 한 방 → **3~12자 이음새를 같은 꼴로 연달아**(리듬) → 화자가 논평 → 구어체
- 마디 하나는 짧게. 나레 초당 4~5.5자.

## 22. ★마무리 공식

> "전투복 이런 마무리 좋아"

**나레가 받침을 깔고 → 인물의 대사가 펀치 → 나레는 감정만 한 줄.**

- **요약하면 감동이 안 온다.** 소재에서 **가장 센 대사 두 개**를 찾아 답과 펀치로 쓴다.
- 사용자가 "여기서 마무리해줘"라고 지정한 편은 **그 지점까지만** 쓴다. (ep07 "이상해 그지")

# 제7부 · 엔진 함정 (겪은 것)

- **`base.crop_filter` 를 그대로 쓰면 안 된다.** base 의 PIC·ZOOM 을 물고 있다. spec 에서 재정의.
- **PIL 로 글꼴을 재면 틀린다.** libass 로 그려서 **잉크 높이**를 재라.
- **`probe()` 는 넓은 판(w=4000)에 그려야** 넘치는 자막을 잡는다. 1080 판에서는 잘려서 못 잡는다.
- **경고를 늦게 `WARN.append` 하면 영영 안 찍힌다.** `[규격 위반]` 칸은 앞에서 한 번만 찍힌다.
  자막 폭처럼 나중에 재는 것은 **그 자리에서 `print`** 한다.
- **`drawtext` 는 이 PC 에서 죽는다** (fontconfig 없음). 쓰지 마라.
- **cp949 콘솔**: `sys.stdout.reconfigure(encoding="utf-8")` + subprocess `encoding="utf-8"`.
- **`\U` 함정**: 셸 heredoc 으로 윈도 경로를 넘기면 유니코드 이스케이프로 깨진다. Write/Edit 를 써라.
- **타입캐스트 402(CREDIT_INSUFFICIENT)**: 스튜디오(웹) 크레딧과 **API 크레딧은 별개**다.
  `/v1/voices` 는 200 인데 `/v1/text-to-speech` 만 402 면 **키 문제가 아니라 API 잔액**이다.
  잔액 조회 API 는 없다. https://typecast.ai/developers/api 에서 확인.
