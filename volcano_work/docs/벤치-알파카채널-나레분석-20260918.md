## 3. 어미 통계 (나레 47마디)

| 어미 | 횟수 | 쓰임 |
|---|---|---|
| **~죠 / ~었죠 / ~는 거죠** | 17 | 마디를 **맺을 때**. 사실을 확정하듯 담담하게. "~였죠·~있었죠·~해주죠·~떠오르죠·~밀려오죠" |
| **~는데 / ~ㄴ데 / ~건데** | 13 | 다음 대사로 **넘길 때**. "들리는데·많아졌는데·넘겼는데·보였는데·건데(×4)" |
| **~기에** | 4 | **이유**를 대고 바로 대사로. "알기에·있기에" — 이 채널 특유 |
| **~지만** | 3 | 반전 앞. "머물고 싶었지만·검사였지만·연락하지만" |
| **~에겐 / ~는 / ~그날** (명사·조사로 끊음) | 5 | 주어만 던지고 **대사가 서술어 노릇**. "비서실장에겐 → 함 가보자", "그녀는 → 일본으로 가는 거 어때요", "그에겐 → 그럴 수 없다는 거…" |
| **~고 / ~며 / ~에도** | 3 | 나열·동시 |
| **반말 종결(~더라·~네·~지·~겠다·~불러)** | 6 (닫는 촌평 전부) | 마지막 한 줄만 |

★**존댓말 "~죠"와 반말 촌평의 2단 구조.** 본문은 전부 "~죠"체(해요체 반말 아님 — 구어 존댓말), 마지막 한 줄만 친구 말투.
★**"~다/~습니다"로 맺는 마디가 0개.** 문어체 종결이 없다.

## 4. 말투 규칙 (뽑아 쓴 것)

1. **3인칭 · 과거형.** "~했죠 / ~였죠 / ~있었죠". 현재형 중계("~한다")를 안 쓴다.
2. **인물은 "자신·그·그녀" 대명사를 자주 쓴다** — 우리 지침(이름으로 부른다)과 반대. 이름은 편당 1~2번(백기태·장검사·천 실장·유지)만, 나머지는 "자신·그녀·옛 동기·오른팔·후배".
3. **나레가 대사를 절대 되풀이하지 않는다.** 대사 앞뒤의 **이유·심리·결과**만 말한다.
   - 이유: "그를 알기에", "자신과 있으면 계속 가면을 쓰고 살 거란 걸 알고 있기에"
   - 심리: "너무나도 달콤했죠", "도저히 이해할 수 없죠", "웃기기만 한데"
   - 결과: "제지당했죠", "다른 사람이 받죠", "후회가 밀려오죠"
4. **주어를 던지고 대사가 받게 한다.** 나레 "힘을 잃은 비서실장에겐" → 대사 "함 가보자" → 나레 "기태의 제안은 너무나도 달콤했죠". 나레 두 마디가 대사 하나를 **샌드위치**.
5. **속어·구어 양념을 나레에 섞는다**: 쥐새끼·나가리·쇼부·뜨내기·극혐·감투·깐죽거림. 한 편에 2~3개.
6. **판단을 나레가 대신 내린다**: "딱 봐도 감시할 목적", "먹잇감이었죠", "선 넘었지". 시청자 대신 화내 준다.
7. **한 마디 = 한 정보.** 접속으로 두 정보를 붙이지 않는다. 긴 마디(ref3-5 "같이 힘을 합쳐도 모자랄 판에 이런 행동을 한 형님을 도저히 이해할 수 없죠" 32자)는 편당 한 번.
8. **닫는 촌평 공식**: 반말 + 감탄/판단 + 마스코트. "~더라 / ~네 / ~지 / ~겠다 / 왜 ~해". 앞 내용을 요약하지 않고 **한 발 물러선 한마디**.
9. **제목이 곧 결론.** "극혐하던 상사처럼 똑같이 변한 장검사" → 나레 마지막 "자신이 제일 극혐하던 사람이 되어 있었죠" → 촌평 "결국 감투 쓰면 다 똑같네". 제목 낱말이 본문에 다시 나온다.
