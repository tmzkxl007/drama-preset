> 사용자: 「이 채널 분석 좀 해줘 조회수가 장난 아닌데 어떤 구조로 나레이션이 들어가고 전개를 해서

세 채널을 yt-dlp 로 긁고, 상위 영상을 받아 배치·컷·나레이션·소리를 실측했다. 결과는 `PLAYBOOK` §16.

**한 줄 결론: 포레이로는 나레이션이 주인이고 드라마는 B롤이다.** 자동자막의 `»`(원본 대사) 개수가
포레이로 3~6회 / 무비대장 26회 / 마음한조각 56회로 갈린다. 나레는 260자·11덩이를 31~42초에 붓고,
**모든 마디를 연결어미로 잇고 마지막도 `~는데` 로 끊어** 결말을 주지 않는다.
0초 프레임은 시간 순서가 아니라 그 편에서 가장 센 그림이고, 첫 3.5초에 5컷을 난사한 뒤 본문은 1~3초 컷으로 늦춘다.

★함정 기록
- **winget 판 yt-dlp 는 못 쓴다**(§ bootstrap 경고 그대로). venv 에 `pip install -U yt-dlp` 해야 채널을 긁는다.
- 자막 트랙을 여러 언어로 한꺼번에 받으면 **429**가 난다. `--sleep-requests 2` + 재시도로 풀린다. 쓸 언어만 받아라.
- 밝기로 그림 영역을 재면 **제목 글자가 섞여 들어온다.** 행 채움률(가로 85% 이상)로 재야 경계가 나온다.
- 자동자막은 굴러가는(rolling) 형식이라 그대로 이으면 문장이 중복된다. 앞 문장이 뒤 문장의 접두어면 대체해야 한다.
