# 포크 지시 — 이미 만든 편을 부록 M-16 비중으로 고치기 (2026-09-19)

먼저 `docs/포크-작업지시-공통.md` 를 읽는다(말투·컷·납품 규칙 전부 그대로). 이 문서는 **기존 편 하나를 고치는** 절차다. 커밋·푸시 금지, 다른 mk* 폴더 금지. 파이프라인은 **포그라운드**에서 timeout 600000 으로 기다린다(백그라운드·Monitor 로 넘기고 멈추지 마라).

## 목표 (기준 편 `mk13c_나레줄임/episode.py`, 재는 도구 `scripts/_share.py`)

- 나레 **5~6마디**(촌평 포함) · 마디 **≤18자** · 편당 **60~90자** · 실제 소리 시간 비중 **20~25%**
- 대사 **10블록 안팎** · 시간 비중 **70% 이상**
- **나레 두 마디 연속 금지** — 사이에 반드시 D. 장면 넘김은 대사→대사로 건너뛰어도 된다.
- 완성 **40~50초**. 말투(부록 M-1~15: ~죠/~는데, 직함 ✗, 쉬운 말, 주인공 입장 촌평)는 그대로.

## 절차

1. `<편>/episode.py` 와 `<편>/asr_ko.json` 을 읽는다. 지금 나레 8마디 중 **장면을 잇는 데 꼭 필요한 것만 5~6개** 남긴다 — 훅(0초) 한 마디, 국면 바뀔 때 한 마디씩, 촌평 한 마디. 나머지는 지운다. 남긴 마디도 18자 안으로 다듬는다(정보 하나만).
2. 지운 나레가 말하던 내용은 **원본 대사로 채운다**: `asr_ko.json` 에서 아직 안 쓴 대사(짧은 반응 "네", "뭔 소리야?", "알겠습니다" 포함)를 D 블록으로 넣어 **10블록 안팎**을 만든다. 불확실한 낱말은 여전히 넣지 않는다. D 블록 = 첫 낱말−0.08 ~ 마지막 낱말+0.30, 자막 한 줄 ~13자.
3. 소재 구간이 모자라면 `prep.py` 로 앞뒤를 더 잘라도 된다(src.mp4 지우고 다시 — asr_ko.json 도 offset 맞춰 다시 슬라이스). 길이가 50초를 넘으면 뜸 긴 대사부터 뺀다.
4. 나레 컷은 마디 길이만큼(짧은 마디 1~2컷), 창 규칙(§12-3) 지킨다. 훅 컷은 그대로 둬도 된다.
5. `dlgcheck.py` 0 → `tts.py`(바뀐 마디만 재합성) → `align.py` → `reframe.py` → `build.py`(위반 전부 고침 — 새 검사: 나레 연속·20자 초과·마디 5~7·글자 60~100·대사 8~14) → `synccheck.py` ≤0.10 → `cutsheet.py` + Read 눈검사.
6. `python scripts\_share.py` 로 그 편의 나레%·대사% 를 확인 — 나레 20~25%·대사 70%+ 가 아니면 2번으로 돌아간다.
7. 납품 덮어쓰기: `~/Downloads/드라마/<편>.mp4`, `포레이로/<편>.mp4`, `포레이로/<편>_업로드.txt`(설명글의 나레 인용·촌평이 바뀌었으면 고친다 · 디즈니 플러스 줄 유지) → Downloads 에도 복사, `~/forey-preset/volcano_work/examples/<편>/` 에 episode.py·업로드.txt 복사.
8. episode.py 머리 docstring 에 한 줄 추가: `★2026-09-19 부록 M-16 비중으로 고침: 나레 8→N마디, 대사 D→M블록`.
